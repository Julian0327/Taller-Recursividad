# Taller-Recursividad

**Estudiante:** Julian Aldemar Perez Elvira

## Descripción
Taller de recursividad en Java con 13 ejercicios resueltos de forma recursiva:

- **Operaciones numéricas**: factorial, sumatoria, serie armónica, potencia y multiplicación por sumas sucesivas.
- **Manejo de dígitos**: inversión de un número y suma de sus dígitos.
- **Algoritmos clásicos**: máximo común divisor (Euclides), cociente por restas sucesivas, serie de Fibonacci y función de Ackermann.
- **Estructuras**: suma de los elementos de un arreglo y de una matriz.

El proyecto está desarrollado con enfoque en Clean Code y los principios SOLID: cada ejercicio es una clase independiente que hereda de `EjercicioBase`, la entrada y salida se abstraen con la interfaz `Consola`, y el menú recibe la lista de ejercicios sin conocer sus detalles. En cada ejercicio se separan la lectura de datos, el cálculo recursivo y la impresión de resultados.

## Estructura del proyecto

- `src/Recursividad/` — ejercicios 1 al 13, App, menú y clases de apoyo

## Ejecución
1. Clonar el repositorio:

git clone https://github.com/Julian0327/Taller-Recursividad.git

2. Abrir el proyecto en NetBeans o VS Code.
3. Ubicar la clase `App.java` dentro de `src/Recursividad`.
4. Ejecutar el programa con el botón **Run** del editor sobre la clase `App`.
5. Seleccionar el ejercicio que se desea ejecutar con el número correspondiente.
6. Seguir las instrucciones que aparecen en consola e ingresar los datos pedidos.
7. Seleccionar la opción 0 para salir del programa.
